# 🍿 CouchPop

CouchPop is a responsive watch-party web application designed to create an interactive experience for users watching movies and shows together.

## Features

- 🌙 Dark mode toggle
- 🎟️ RSVP form for joining the watch party
- ✅ Client-side form validation
- 🎉 Personalized RSVP confirmation modal
- 🍿 Animated modal interaction
- 📱 Responsive design

## Technologies

- HTML
- CSS
- JavaScript
